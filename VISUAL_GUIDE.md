## 🆘 Решение проблем / Troubleshooting

```
❌ Ошибка                  ✅ Решение
─────────────────────────────────────────────
Python not found       →  Установите Python
                          python.org

Port 5000 in use       →  Измените PORT в .env
                          PORT=5001

Cannot connect to DB   →  Запустите PostgreSQL
                          Проверьте пароль

Module not found       →  Запустите setup снова
                          pip install -r requirements.txt

Docker not running     →  Запустите Docker Desktop
```
