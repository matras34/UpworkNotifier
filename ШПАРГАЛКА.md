# ⚡ БЫСТРАЯ ШПАРГАЛКА

## 🚀 Быстрый старт за 5 минут

### 1️⃣ Установите PostgreSQL
```
Windows: https://www.postgresql.org/download/windows/
Mac:     brew install postgresql@14 && brew services start postgresql@14
Linux:   sudo apt install postgresql && sudo systemctl start postgresql
```
**Пароль:** `postgres` (запомните его!)

---

### 2️⃣ Установите Redis (опционально)
```
Windows: https://github.com/microsoftarchive/redis/releases
Mac:     brew install redis && brew services start redis
Linux:   sudo apt install redis-server && sudo systemctl start redis-server
```

---

### 3️⃣ Проверьте файл .env
```
Откройте: backend-python/.env

Проверьте:
DB_PASSWORD=postgres  ← ваш пароль от PostgreSQL!
```

---

### 4️⃣ Запустите сервер
```
Windows:    Дважды кликните backend-python/start.bat
Mac/Linux:  cd backend-python && ./start.sh
```

---

### 5️⃣ Откройте в браузере
```
http://localhost:5000
```

---

### 6️⃣ Войдите
```
Email:    admin@example.com
Password: admin123
```

---

## ✅ Готово!

Теперь:
1. Нажмите "+ New Connection"
2. Введите данные вашего SSH сервера
3. Нажмите "Connect"
4. Работайте в терминале!

---

## 🆘 Проблемы?

**База не подключается:**
→ Проверьте что PostgreSQL запущен
→ Проверьте пароль в .env

**Порт занят:**
→ Измените PORT=5001 в .env
→ Откройте http://localhost:5001

**Module not found:**
→ Запустите setup.bat/setup.sh снова
