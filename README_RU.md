# 🚀 Web SSH - Терминал в Браузере (Очень Просто!)

**Подключайтесь к вашим серверам через браузер - никаких сложных настроек!**

## 📺 Что это?

Это веб-приложение, которое позволяет подключаться к SSH серверам прямо в браузере.
Не нужно устанавливать PuTTY или другие программы!

## ⚡ Быстрая установка (3 способа)

### Способ 1: Docker (САМЫЙ ПРОСТОЙ) ⭐

1. Установите [Docker Desktop](https://www.docker.com/products/docker-desktop)
2. Дважды кликните по файлу:
   - **Windows**: `install.bat`
   - **Linux/Mac**: `install.sh`
3. Откройте http://localhost в браузере
4. Готово! 🎉

### Способ 2: Python (Без Docker)

**Windows:**
1. Установите [Python 3.11+](https://www.python.org/downloads/)
2. Установите [PostgreSQL](https://www.postgresql.org/download/)
3. Запустите `backend-python/setup.bat`
4. Запустите `backend-python/start.bat`

**Linux/Mac:**
```bash
cd backend-python
./setup.sh
./start.sh
```

### Способ 3: Онлайн (Самый быстрый для теста)

Разверните на [Heroku](https://www.heroku.com/) или [Railway](https://railway.app/) одним кликом (инструкция внутри)

## 🔑 Первый вход

После установки откройте http://localhost:

```
Email:    admin@example.com
Password: admin123
```

**⚠️ ВАЖНО: Смените пароль после первого входа!**

## 💻 Как использовать

1. **Войдите** в систему
2. **Нажмите "New Connection"**
3. **Введите данные вашего сервера:**
   - Название (например, "Мой сервер")
   - IP адрес (например, 192.168.1.100)
   - Порт (обычно 22)
   - Логин
   - Пароль или SSH ключ
4. **Нажмите "Connect"**
5. **Готово!** Терминал откроется прямо в браузере

## 🛠️ Что делать если что-то не работает?

### Проблема: "Не могу запустить"

**Docker:**
- Убедитесь, что Docker Desktop запущен
- Перезапустите Docker Desktop
- Запустите: `docker-compose restart`

**Python:**
- Проверьте, что PostgreSQL работает
- Проверьте файл `.env` в папке `backend-python`
- Посмотрите логи: `python run.py`

### Проблема: "Не могу подключиться к серверу"

- Проверьте, что SSH сервер доступен (ping адрес)
- Проверьте порт (обычно 22)
- Убедитесь, что логин и пароль правильные
- Проверьте firewall на сервере

### Проблема: "Забыл пароль"

Создайте нового пользователя через API:
```bash
curl -X POST http://localhost:5000/api/v1/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email":"newuser@example.com","password":"newpassword"}'
```
