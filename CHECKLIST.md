# ✅ Checklist для начала работы / Getting Started Checklist

## 📋 Перед установкой / Before Installation

- [ ] У вас есть компьютер с Windows, Mac или Linux
- [ ] У вас есть права администратора
- [ ] Вы можете скачивать файлы из интернета
- [ ] У вас есть 5GB свободного места на диске

## 🐳 Вариант 1: Docker (Рекомендуется для начинающих)

### Шаг 1: Установка Docker
- [ ] Скачал Docker Desktop с https://www.docker.com/products/docker-desktop
- [ ] Установил Docker Desktop
- [ ] Запустил Docker Desktop
- [ ] Проверил что Docker работает (docker --version)

### Шаг 2: Установка приложения
- [ ] Открыл папку проекта
- [ ] Дважды кликнул `install.bat` (Windows) или `./install.sh` (Mac/Linux)
- [ ] Подождал окончания установки (2-3 минуты)
- [ ] Увидел сообщение "Installation complete!"

### Шаг 3: Проверка
- [ ] Открыл браузер
- [ ] Перешел на http://localhost
- [ ] Увидел страницу входа

### Шаг 4: Первый вход
- [ ] Ввел email: admin@example.com
- [ ] Ввел password: admin123
- [ ] Нажал Login
- [ ] Попал в Dashboard

### Шаг 5: Смена пароля
- [ ] Открыл настройки профиля
- [ ] Сменил пароль по умолчанию
- [ ] Запомнил новый пароль

## 🐍 Вариант 2: Python (Без Docker)

### Шаг 1: Установка зависимостей
- [ ] Скачал Python 3.11+ с https://www.python.org/downloads/

- [ ] Проверил установку (python --version)

- [ ] Подождал установки зависимостей

## 🔌 Создание первого подключения

### SSH Сервер готов
- [ ] У меня есть SSH сервер для подключения
- [ ] Я знаю IP адрес сервера
- [ ] Я знаю логин
- [ ] Я знаю пароль или имею SSH ключ

### Создание подключения
- [ ] Нажал "+ New Connection"
- [ ] Ввел название (например, "Мой сервер")
- [ ] Ввел хост (IP адрес, например 192.168.1.100)
- [ ] Ввел порт (обычно 22)
- [ ] Ввел username (логин)
- [ ] Выбрал тип авторизации (Password или Private Key)
- [ ] Ввел пароль или вставил приватный ключ
- [ ] Нажал "Save"

### Подключение
- [ ] Нажал кнопку "Connect" у сохраненного подключения
- [ ] Увидел терминал
- [ ] Терминал показывает приглашение командной строки
- [ ] Могу вводить команды

## 🔧 Решение проблем

### Docker не запускается
- [ ] Проверил что Docker Desktop запущен
- [ ] Перезапустил Docker Desktop
- [ ] Перезагрузил компьютер
- [ ] Проверил в логах ошибки: `docker-compose logs -f`

### Python не находится
- [ ] Переустановил Python с галочкой "Add to PATH"
- [ ] Открыл новый терминал (командную строку)
- [ ] Проверил: `python --version`

### База данных не подключается
- [ ] Проверил что PostgreSQL запущен
- [ ] Проверил пароль в файле .env
- [ ] Проверил что порт 5432 свободен
- [ ] Попробовал подключиться вручную: `psql -U postgres`

### Порт занят
- [ ] Открыл файл .env
- [ ] Изменил PORT на другой (например 5001)
- [ ] Перезапустил приложение
