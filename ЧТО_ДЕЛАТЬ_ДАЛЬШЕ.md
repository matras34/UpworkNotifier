## 🎯 ШАГ 1: Установите PostgreSQL (База данных)

PostgreSQL - это база данных, которая нужна для работы приложения.

### Для Windows:

1. **Скачайте PostgreSQL:**
   - Откройте в браузере: https://www.postgresql.org/download/windows/
   - Нажмите "Download the installer"
   - Выберите последнюю версию (например, PostgreSQL 16.x)
   - Скачайте установщик

2. **Установите PostgreSQL:**
   - Запустите скачанный файл `.exe`
   - Следуйте инструкциям установщика:
     - **Пароль для пользователя postgres:** введите `postgres` (или запомните свой пароль)
     - **Порт:** оставьте `5432` (по умолчанию)
     - Все остальное - по умолчанию (просто нажимайте "Next")
   
3. **Проверьте что PostgreSQL запущен:**
   ```cmd
   # Откройте командную строку (Win + R, введите cmd, Enter)
   # Проверьте версию:
   psql --version
   ```
   
   Должно показать что-то вроде: `psql (PostgreSQL) 16.1`

### Для Mac:

1. **Установите через Homebrew:**
   ```bash
   # Если Homebrew не установлен, сначала установите его:
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   
   # Установите PostgreSQL:
   brew install postgresql@14
   
   # Запустите PostgreSQL:
   brew services start postgresql@14
   ```

2. **Проверьте:**
   ```bash
   psql --version
   ```

### Для Linux (Ubuntu/Debian):

```bash
# Обновите пакеты
sudo apt update

# Установите PostgreSQL
sudo apt install postgresql postgresql-contrib

# Запустите службу
sudo systemctl start postgresql
sudo systemctl enable postgresql

# Проверьте статус
sudo systemctl status postgresql
```

### ✅ Как понять что PostgreSQL работает?

**Windows:** 
- Нажмите `Win + R`, введите `services.msc`, Enter
- Найдите "postgresql" в списке
- Должно быть написано "Выполняется" (Running)

**Mac/Linux:**
```bash
# Проверьте что служба запущена
pg_isready
```

Должно показать: `/tmp:5432 - accepting connections`

## 🎯 ШАГ 2: Установите Redis (Опционально, но рекомендуется)

Redis используется для кэширования и управления сессиями.

### Для Windows:

**Вариант 1: Redis для Windows (старая версия, но работает)**
1. Скачайте: https://github.com/microsoftarchive/redis/releases
2. Скачайте файл `Redis-x64-3.0.504.msi`
3. Установите как обычную программу
4. Redis запустится автоматически как служба

**Вариант 2: Используйте Docker (рекомендуется)**
```cmd
# Если у вас установлен Docker:
docker run -d -p 6379:6379 --name redis redis:alpine
```

### Для Mac:

```bash
# Установите через Homebrew
brew install redis

# Запустите Redis
brew services start redis

# Проверьте
redis-cli ping
```

Должно ответить: `PONG`

### Для Linux:

```bash
# Ubuntu/Debian
sudo apt install redis-server

# Запустите
sudo systemctl start redis-server
sudo systemctl enable redis-server

# Проверьте
redis-cli ping
```

### ⚠️ Если не хотите устанавливать Redis

Redis опционален. Если не хотите его устанавливать:
1. Откройте файл `.env` в папке `backend-python`
2. Закомментируйте строки про Redis (добавьте `#` в начале)

## 🎯 ШАГ 4: Настройте файл .env (Конфигурация)

Это важно! Нужно настроить подключение к базе данных.

1. **Откройте папку `backend-python`**

2. **Найдите файл `.env`**
   - Если его нет, скопируйте `.env.example` и переименуйте в `.env`

3. **Откройте `.env` в текстовом редакторе** (Блокнот, Notepad++, VS Code)

4. **Проверьте эти строки:**
   ```
   DB_HOST=localhost
   DB_PORT=5432
   DB_USER=postgres
   DB_PASSWORD=postgres    ← ИЗМЕНИТЕ если у вас другой пароль!
   DB_NAME=webssh
   ```

5. **Сохраните файл**

## 🎯 ШАГ 8: Создайте первое SSH подключение

1. **Нажмите кнопку "+ New Connection"**

2. **Заполните форму:**
   ```
   Name:     Мой сервер          (любое название)
   Host:     192.168.1.100       (IP вашего SSH сервера)
   Port:     22                  (обычно 22)
   Username: root                (ваш логин на сервере)
   Auth:     Password            (выберите тип авторизации)
   Password: ваш_пароль          (пароль от SSH сервера)
   ```

3. **Нажмите "Save"** - подключение сохранится

4. **Нажмите "Connect"** - откроется терминал!

### ✅ Подключение успешно, если:

- Открылось окно терминала
- Видите приглашение командной строки (например, `root@server:~$`)
- Можете вводить команды

## 🔧 Что-то пошло не так? Решения проблем

### ❌ Ошибка: "Cannot connect to database"

**Причина:** PostgreSQL не запущен или неверный пароль

**Решение:**
1. Проверьте что PostgreSQL запущен (см. Шаг 1)
2. Проверьте пароль в файле `.env` (Шаг 4)
3. Попробуйте подключиться вручную:
   ```cmd
   psql -U postgres -h localhost
   ```

### ❌ Ошибка: "Port 5000 is already in use"

**Причина:** Порт 5000 занят другой программой

**Решение:**
1. Откройте `.env`
2. Измените:
   ```
   PORT=5001
   ```
3. Перезапустите сервер
4. Открывайте в браузере: http://localhost:5001

### ❌ Ошибка: "Module not found" или "No module named 'flask'"

**Причина:** Зависимости не установлены

**Решение:**
1. Закройте сервер (Ctrl+C)
2. Запустите снова `setup.bat` (Windows) или `./setup.sh` (Mac/Linux)
3. Дождитесь окончания установки
4. Запустите `start.bat` снова

### ❌ Сервер запускается, но браузер не открывает страницу

**Решение:**
1. Проверьте что сервер действительно запущен (не закрыли окно)
2. Попробуйте другие адреса:
   - http://localhost:5000
   - http://127.0.0.1:5000
   - http://0.0.0.0:5000
3. Проверьте firewall - он может блокировать

### ❌ "Connection refused" при подключении к SSH

**Причины:**
1. Неверный IP адрес сервера
2. SSH сервер не запущен на удаленном сервере
3. Неверный порт (обычно 22)
4. Firewall блокирует соединение

**Решение:**
1. Проверьте что SSH сервер доступен:
   ```cmd
   ping 192.168.1.100
   telnet 192.168.1.100 22
   ```
2. Проверьте логин и пароль
3. Убедитесь что порт 22 открыт

## 🎉 Готово!

Теперь у вас работает Web SSH терминал в браузере!

### Что можно делать дальше:

1. **Добавить больше серверов**

   - Добавьте все ваши серверы

2. **Создать других пользователей**

3. **Сменить пароль администратора**
   - Это важно для безопасности!
   - В настройках профиля смените пароль

4. **Настроить HTTPS** (для продакшена)
   - Используйте nginx как reverse proxy
   - Получите SSL сертификат (Let's Encrypt)

5. **Включить резервное копирование**
   - Настройте backup для PostgreSQL
